# React приложение с карточками персонажей

## 🎯 О проекте

Приложение загружает и отображает список персонажей из API Rick and Morty в виде карточек с изображениями.

## 🚀 Функционал

- Загрузка данных о персонажах с внешнего API
- Отображение карточек в грид-сетке
- Отображение текста "Загрузка..." на месте картинки, пока она не загрузилась
- Если картинка не загрузилась — на её месте отображается текст из атрибута `alt`

## 🛠️ Технологии

- React (useState, useEffect)
- TypeScript
- CSS Modules
- Vite

## 📦 Установка и запуск

```bash
npm install
npm run dev
```
