# React приложение с карточками персонажей

## 🎯 О проекте

Приложение загружает и отображает список персонажей из вселенной Гарри Поттера в виде карточек с изображениями.

## 🚀 Функционал

- Загрузка данных о персонажах с внешнего API
- Отображение карточек в грид-сетке
- Отображение текста **"⏳ Загрузка..."** на месте картинки, пока она не загрузилась
- Если картинка не загрузилась — на её месте отображается иконка **❌** и текст **"Не удалось загрузить"**
- При наведении на имя персонажа появляется всплывающая подсказка с полным именем

## 🛠️ Технологии

- React (useState, useEffect)
- TypeScript (interface)
- CSS Modules
- Vite

## 📦 Установка и запуск

```bash
npm install
npm run dev
```
