# React приложение с карточками персонажей

## 🎯 О проекте

Приложение загружает и отображает список персонажей из вселенной Гарри Поттера в виде карточек с изображениями.

## 🚀 Функционал

- Загрузка данных о персонажах с внешнего API
- Отображение карточек в виде сетки
- Отображение текста **"⏳ Загрузка..."** или **❌ Не удалось загрузить"** на месте картинки в соответствующих случаях
- При наведении на имя персонажа появляется всплывающая подсказка с полным именем
- Поиск по никнейму или полному имени с кнопкой очистки 
- Адаптивная вёрстка (5 колонок на десктопе, 3 на мобильных устройствах) с автоматическим пересчётом количества карточек
- Пагинация (разбивка на страницы) с адаптивным количеством карточек (10 на десктопе, 6 на мобильных устройствах) с блокировкой кнопки текущей страницы

## 🛠️ Технологии

- React (useState, useEffect)
- TypeScript (interface)
- CSS Modules
- Vite

## 📦 Установка и запуск

```bash
npm install
npm run dev
```
